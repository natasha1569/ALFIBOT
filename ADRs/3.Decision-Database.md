# Database Decisions

Date: 2026-08-13

1. ALFI BOT uses PostgreSQL as the database engine.
2. PostgreSQL protects data with primary keys, foreign keys, CHECK, UNIQUE, DEFAULT, and null rules.
3. Database audit uses functions and triggers to record INSERT, UPDATE, and DELETE operations.
4. Reports use SQL views to keep important read logic in one place.
5. PostgreSQL uses RBAC roles and minimum privileges.
6. `backend/sql/ALFI_BOT_DATABASE.sql` is the main file for the ALFI BOT database model.
7. The main SQL installer must work on a new database.
8. The installer must also work again on an existing database without deleting business data or making duplicate seed data.
9. Old `AFB-*.sql` files stay as project history, but they do not replace the main installer.
