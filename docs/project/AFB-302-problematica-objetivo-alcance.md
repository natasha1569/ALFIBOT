# AFB-302 — Problemática, objetivo y alcance

## Problemática
Las inversiones falsas, préstamos engañosos, esquemas piramidales y otras ofertas financieras fraudulentas pueden ser difíciles de identificar. ALFI BOT busca ayudar al usuario a reconocer señales de alerta antes de tomar una decisión financiera.

## Objetivo
Desarrollar una aplicación web que analice contenido potencialmente fraudulento y muestre nivel de riesgo, señales detectadas y recomendaciones preventivas.

## Alcance
- Landing pública.
- Registro e inicio de sesión.
- Recuperación de contraseña.
- Acceso protegido por rol.
- Análisis de texto, enlaces e imágenes.
- Clasificación de riesgo.
- Categorización de fraudes.
- Señales y recomendaciones.
- Historial.
- PostgreSQL.
- RBAC y auditoría.
- Reporterías y vistas.
- Documentación técnica mediante ADRs.
