# Frontend Decisions

Date: 2026-08-13

1. ALFI BOT uses React to build the web interface with components.
2. React components made by the project use PascalCase names.
3. We reuse components when possible. We do not copy the same interface many times.
4. Bootstrap 5 is the main visual framework. Bootstrap Icons is used for icons.
5. React hooks are used at the top level of components and not inside conditions.
6. The interface can change by user role, but the frontend does not give security permission.
7. API access, authentication, and utility logic stay in separate modules when possible.
