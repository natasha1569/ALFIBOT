# AFB-284 — Cierre de preparación para sustentación

## Criterios de cierre
- Documentación técnica disponible.
- Explicación de frontend preparada.
- Explicación de backend preparada.
- Explicación de base de datos preparada.
- Casos de riesgo bajo, medio y alto preparados.
- Prueba integral final ejecutada.
- Repositorio limpio.
- Ensayo de sustentación realizado.
- Jira y Confluence actualizados.
- Evidencias finales disponibles.

## Estado
Este documento centraliza el cierre. La tarea debe marcarse Finalizada solamente cuando la prueba integral, limpieza y ensayo estén realmente completados.

## Alcance comercial actualizado

ALFI BOT no incluye un módulo de licencias comerciales en el alcance final del proyecto.

El modelo planteado para usuarios finales es de acceso gratuito. Como visión de monetización a mediano plazo, el sistema podrá incorporar publicidad relacionada con servicios o productos financieros utilizando tendencias agregadas de uso y riesgo.

Esta estrategia deberá respetar la privacidad de los usuarios y no podrá implicar la venta o exposición de contraseñas, credenciales, datos sensibles ni información personal identificable.
