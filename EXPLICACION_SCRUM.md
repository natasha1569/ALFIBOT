# Explicación de Scrum y Gestión del Proyecto - ALFI BOT

## 1. Metodología utilizada

Para el desarrollo de ALFI BOT utilizamos la metodología ágil Scrum, que permitió organizar el proyecto en tareas pequeñas, distribuir responsabilidades entre los integrantes del equipo y realizar un seguimiento constante del avance.

El trabajo fue administrado mediante Jira, donde se registraron las épicas, historias de usuario y tareas necesarias para desarrollar el sistema.

## 2. Organización del trabajo

El proyecto se dividió en diferentes actividades relacionadas con:

- Diseño y desarrollo del sistema.
- Frontend.
- Backend.
- Base de datos.
- Integración de funcionalidades.
- Pruebas.
- Documentación.
- Preparación de la presentación final.

Cada integrante tuvo tareas asignadas dentro de Jira, permitiendo identificar quién era responsable de cada actividad y conocer su estado.

## 3. Uso del Product Backlog

En el Product Backlog se registraron las funcionalidades y actividades necesarias para completar ALFI BOT.

Las tareas fueron organizadas y priorizadas de acuerdo con las necesidades del proyecto.

Los estados utilizados permitieron identificar las actividades:

- Por hacer.
- En curso.
- Finalizadas.

## 4. Sprint Planning

Durante el Sprint Planning se seleccionaron las actividades que debían desarrollarse durante el Sprint.

El equipo revisó las tareas pendientes, distribuyó responsabilidades y estableció qué actividades debían completarse para avanzar con el proyecto.

## 5. Daily Scrum

Las reuniones Daily Scrum permitieron revisar periódicamente el avance del equipo.

Durante estas reuniones se analizaron tres puntos principales:

1. Qué actividades se habían realizado.
2. Qué actividades se realizarían después.
3. Qué problemas o impedimentos existían.

Esto permitió detectar dificultades y mantener organizado el trabajo del equipo.

## 6. Seguimiento mediante Jira

Jira fue utilizado como herramienta principal para gestionar el proyecto.

Mediante Jira se pudo:

- Crear épicas.
- Crear historias de usuario y tareas.
- Asignar responsables.
- Organizar el Product Backlog.
- Gestionar el Sprint.
- Actualizar el estado de las actividades.
- Dar seguimiento al avance del proyecto.

## 7. Trabajo realizado

Durante el proyecto se desarrollaron diferentes componentes necesarios para el funcionamiento de ALFI BOT.

El equipo trabajó de manera organizada en las actividades asignadas y las tareas terminadas fueron actualizadas en Jira para mantener un registro del progreso.

También se documentaron los avances, problemas encontrados y soluciones aplicadas durante el desarrollo.

## 8. Resultado de aplicar Scrum

La utilización de Scrum permitió mantener una mejor organización del proyecto, dividir el trabajo entre los integrantes y realizar seguimiento de las actividades.

Jira facilitó visualizar el avance del proyecto y comprobar qué tareas estaban pendientes, en desarrollo o finalizadas.

De esta manera, el equipo pudo trabajar de forma colaborativa hasta completar las funcionalidades planificadas para ALFI BOT.
