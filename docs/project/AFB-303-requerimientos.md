# AFB-303 — Requerimientos funcionales y no funcionales

## Funcionales
- RF-01 Registrar usuarios.
- RF-02 Iniciar y cerrar sesión.
- RF-03 Recuperar contraseña.
- RF-04 Controlar acceso por rol.
- RF-05 Analizar texto, enlaces e imágenes.
- RF-06 Mostrar riesgo, resumen, señales y recomendaciones.
- RF-07 Categorizar fraudes financieros.
- RF-08 Consultar historial.
- RF-09 Gestionar funciones administrativas autorizadas.
- RF-10 Registrar auditoría.
- RF-11 Consultar reportería agregada.
- RF-12 Mantener documentación de licencias y dependencias.

## No funcionales
- Seguridad mediante hash, autenticación y autorización.
- Integridad mediante PK, FK, UNIQUE, CHECK y NOT NULL.
- Trazabilidad Git/GitHub, Jira y Confluence.
- Arquitectura modular frontend/backend.
- Interfaz comprensible.
- Respaldo y restauración de PostgreSQL.
- Auditoría de operaciones relevantes.
