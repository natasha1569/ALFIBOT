# Backend Decisions

Date: 2026-08-13

1. ALFI BOT backend uses Node.js and Express.
2. The frontend talks to the backend with a REST API.
3. API responses use JSON.
4. API errors use clear HTTP status codes and clear messages.
5. The backend validates input even when the frontend also validates it.
6. Routes, controllers, services, configuration, and middlewares have separate jobs.
7. The current academic version is single-company.
8. We do not add `tenantId`, `organizationId`, or multi-tenancy without a new approved need.
9. OpenAI integration stays inside the service layer.
10. AI domain rules are controlled by the central AI policy.
11. Express route files only declare endpoints, middleware, and controllers.
12. Controllers coordinate HTTP contracts; services hold business rules; repositories own persistence.
13. Tests live in `__test__` folders beside the module family they validate.
