# AFB-276 — Distribución de temas para la sustentación

## Objetivo

Definir la distribución final de los temas de la sustentación técnica de ALFI BOT entre los integrantes del equipo, asegurando que cada persona tenga responsabilidades claras y que todos conozcan el flujo general del sistema.

## Integrantes

- Natasha Erazo
- Danny Baquero
- Romel Arévalo

## Distribución de temas

### Natasha Erazo

Responsable de presentar:

- Frontend desarrollado con React.
- Experiencia de usuario.
- Validaciones del frontend.
- Navegación.
- Vistas y funcionalidades según rol.
- Integración del frontend con la API REST.
- Evidencias del proyecto en Jira.
- Documentación en Confluence.
- Flujo general de uso de ALFI BOT.

### Danny Baquero

Responsable de presentar:

- Backend desarrollado con Node.js y Express.
- API REST.
- Endpoints principales.
- Autenticación.
- Autorización.
- Integración con OpenAI.
- Manejo de errores.
- Pruebas automatizadas.
- Integración entre frontend y backend.

### Romel Arévalo

Responsable de presentar:

- PostgreSQL.
- Modelo de datos.
- Claves primarias y foráneas.
- Restricciones.
- Auditoría.
- Triggers.
- Vistas de reportería.
- RBAC.
- Roles y privilegios.
- Respaldo y restauración.

## Responsabilidad compartida

Aunque cada integrante tiene un bloque principal asignado, todos deben conocer:

- El problema que resuelve ALFI BOT.
- El objetivo del proyecto.
- La arquitectura general.
- El flujo de análisis.
- Los principales módulos.
- Las tecnologías utilizadas.
- Las pruebas realizadas.
- La metodología Scrum utilizada.
- La visión de monetización futura.

## Orden sugerido de participación

1. Introducción general del proyecto.
2. Natasha: frontend y experiencia de usuario.
3. Danny: backend e integración.
4. Romel: base de datos y seguridad.
5. Demostración funcional.
6. Pruebas y evidencias.
7. Scrum, Jira, Confluence y GitHub.
8. Conclusiones y preguntas.

## Resultado

La distribución de temas queda definida de forma clara para la sustentación final de ALFI BOT.

Cada integrante tiene responsabilidades específicas y el equipo debe mantener conocimiento general del sistema para responder preguntas durante la evaluación.
