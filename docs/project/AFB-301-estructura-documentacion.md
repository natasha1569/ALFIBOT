# AFB-301 — Crear y estructurar la página principal de documentación

La documentación central de ALFI BOT se organiza a partir de la página AFB-252 / T-17 en Confluence.

## Estructura
1. Descripción general.
2. Problemática, objetivo y alcance.
3. Requerimientos.
4. Arquitectura.
5. Base de datos.
6. Perfiles.
7. Casos de uso.
8. Pruebas y evidencias.
9. ADRs y convenciones.
10. Evidencia Git/Jira/Confluence.

## Fuentes de verdad
- Jira: backlog, estados y criterios.
- GitHub: código y documentación versionada.
- Confluence: documentación consolidada.
