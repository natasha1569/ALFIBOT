# AFB-306 — Perfiles de usuarios

## Usuario
Puede registrarse, iniciar sesión, realizar análisis y consultar información asociada a su cuenta.

## Administrador
Gestiona funciones administrativas autorizadas y requiere privilegios elevados.

## Auditor
Consulta información de trazabilidad y auditoría sin asumir todas las funciones del administrador.

## Seguridad
Se aplica RBAC y mínimo privilegio.
