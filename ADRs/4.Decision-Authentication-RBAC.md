# Authentication and RBAC Decisions

Date: 2026-08-13

1. Protected operations use authentication tokens checked by the backend.
2. The backend is the security authority.
3. Hiding buttons or pages in the frontend is not a security rule.
4. The main ALFI BOT roles are `usuario`, `auditor`, and `administrador`.
5. Protected endpoints must use authentication and authorization rules in the backend.
6. The frontend uses role-based pages only to improve the user experience.
7. PostgreSQL uses separate RBAC roles with minimum privileges.
8. A new page or button does not give permission by itself.
9. Every new protected action needs a backend permission rule.
