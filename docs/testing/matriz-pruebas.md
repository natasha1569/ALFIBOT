# AFB-259 - Matriz de Pruebas Funcionales

## Objetivo

Definir una plantilla estándar para registrar y documentar las pruebas funcionales realizadas en ALFI BOT, permitiendo verificar el funcionamiento de las principales funcionalidades del sistema.

## Estados de prueba

- Pendiente: la prueba todavía no ha sido ejecutada.
- Aprobada: el resultado obtenido coincide con el resultado esperado.
- Fallida: el resultado obtenido no coincide con el esperado.

## Descripción de los campos

- **ID:** identificador único de la prueba.
- **Módulo:** sección del sistema que será evaluada.
- **Funcionalidad:** función específica que se desea comprobar.
- **Precondición:** condición que debe cumplirse antes de ejecutar la prueba.
- **Pasos de prueba:** acciones que debe realizar el usuario.
- **Datos de entrada:** información utilizada durante la prueba.
- **Resultado esperado:** comportamiento correcto que debería presentar el sistema.
- **Resultado obtenido:** comportamiento observado durante la ejecución.
- **Estado:** Pendiente, Aprobada o Fallida.
- **Evidencia:** captura de pantalla, archivo o referencia que demuestre la ejecución.

## Módulos considerados

La plantilla puede utilizarse para documentar pruebas de:

- Registro de usuarios.
- Inicio y cierre de sesión.
- Análisis de contenido.
- Análisis de enlaces.
- Análisis de imágenes.
- Historial de análisis.
- Gestión de usuarios.
- Funciones administrativas.
- Validaciones del backend.
- Base de datos.

## Resultado

La matriz proporciona una estructura uniforme para registrar las pruebas funcionales de ALFI BOT y conservar evidencia de los resultados obtenidos.
